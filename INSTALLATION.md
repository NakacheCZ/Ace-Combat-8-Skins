# Installation

These skins are designed to be installed using **Ace Combat 8 SKIN STUDIO** and require **ACE8 MOD LAUNCHER AND LOADER** to function.

## Requirements

Before installing a skin, download and set up:

- [Ace Combat 8 SKIN STUDIO](https://www.nexusmods.com/acecombat8wingsoftheve/mods/52)
- [ACE8 MOD LAUNCHER AND LOADER](https://www.nexusmods.com/acecombat8wingsoftheve/mods/64)

Both utilities are available on Nexus Mods. Follow their respective setup instructions before importing any skins from this repository.

## Installing a skin

1. Download the desired skin ZIP from this repository's **Releases** page.
2. Open **Ace Combat 8 SKIN STUDIO** and configure it for your Ace Combat 8 installation if you have not already done so.
3. Open **Skin slots** and select **Import a skin mod**.
4. Select the downloaded skin ZIP. Import the ZIP directly rather than manually extracting and copying its contents.
5. Allow Skin Studio to finish importing the skin and rebuilding the required skin lists.
6. Start the game through **ACE8 Mod Launcher** using **Modded → Play**.
7. Select the newly installed skin in the aircraft's skin selection menu.

Skin Studio is intended to manage additional skin slots and resolve slot conflicts when multiple compatible skin mods are installed.

## Removing a skin

Remove the skin through **Ace Combat 8 SKIN STUDIO** and allow the tool to rebuild the skin list. Avoid manually deleting shared skin-list files when other additional-slot skins are installed.

## Troubleshooting

If a skin does not appear:

- make sure both **Ace Combat 8 SKIN STUDIO** and **ACE8 MOD LAUNCHER AND LOADER** are installed and configured correctly;
- make sure you imported the downloaded skin ZIP through Skin Studio;
- launch the game through **ACE8 Mod Launcher → Modded → Play** rather than the normal unmodded launch option;
- restart the game after changing skin files, icons or skin-list data;
- check the Skin Studio and Mod Launcher/Loader Nexus Mods pages for current setup instructions and known issues.

Always follow the latest instructions supplied by the authors of Skin Studio and the Mod Launcher/Loader, as their installation process may change with future versions.
