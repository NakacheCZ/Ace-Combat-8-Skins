# Installation

## Installing a skin

1. Download the desired archive from the repository's **Releases** page.
2. Extract the downloaded archive.
3. Follow any skin-specific instructions included with that release.
4. Copy the supplied mod files to the appropriate Ace Combat 8 mod directory.
5. Start the game and verify that the replacement skin appears on the intended aircraft/skin slot.

## Removing a skin

Remove the files installed by that skin from your mod directory. If a release contains additional removal instructions, follow those instructions instead.

## Compatibility

Individual releases may replace specific aircraft skin slots and can conflict with another mod targeting the same files or slot. Check the release notes before installing multiple skins for the same aircraft.

## Troubleshooting

If a skin does not appear:

- confirm that the archive was extracted rather than placed in the game as a ZIP file;
- confirm that the files are in the correct mod directory;
- check whether another installed skin replaces the same aircraft/slot;
- check the release notes for version-specific requirements.

More detailed instructions will be added as the AC8 modding workflow develops.
